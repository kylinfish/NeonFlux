# 軌道式排版(Track Layout)— 設計文件

**日期:** 2026-10-13
**狀態:** 已核准設計,實作中

## 目標

讓使用者自訂分類卡片的位置:資料量大的分類**獨佔一整軌**(縱向整條),資料量小的分類可以**兩個以上疊在同一軌**。

## 設計決定(已確認)

- **模型**:欄(track)→ 堆疊卡片;不做跨軌寬度、不做自由座標。
- **軌數**:不限,由使用者在編輯模式用 **＋** 新增、**×** 刪除空軌。
- **一畫面顯示軌數**:`ui.colCount`(1–4)決定每軌寬度;軌數超過時 `#grid` 橫向滾動。
- **高度**:填滿視窗高度,同軌卡片平分高度,卡片內各自捲動(整頁不捲動)。
  `perCategoryLimit` 不再決定卡片高度,只決定最多列出幾筆。
- **編輯方式**:header「編輯排版」按鈕 → 拖曳(HTML5 DnD,拖到左右邊緣自動捲動)→「完成」才寫入;`Esc` 取消還原。
- **免第三方函式庫**:vanilla JS,無需 vendor。

## 資料模型

```js
settings.ui.layout = { tracks: [['gdocs'], ['gitlab', 'jira'], ['figma', 'linear']] }
```
放在 `ui` 底下,export/import 整個 `settings` 時自動帶上。

## `normalizeLayout(layout, enabledKeys, colCount)`(`src/layout.js`,純函式)

| 情況 | 處理 |
|---|---|
| 無 `layout` 或 `tracks` 為空(舊使用者) | 依分類順序輪流分配到 `colCount` 軌(round-robin) |
| 分類在 layout 中但已停用 / 刪除 / 重複 | 移除 |
| 啟用中但不在 layout | 放到卡片最少的那一軌最下面 |
| 軌數 > 一畫面顯示軌數 | 全部保留(橫向滾動),不併軌 |
| 使用者新增的空軌 | 保留 |

渲染時才 normalize,不回寫 storage;只有按「完成」才儲存。

## 渲染

- `#grid` 為橫向 flex 容器,每個 `.track` 寬度 = (100% − gaps) ÷ `colCount`;軌內卡片 `flex: 1 1 0`。
- 編輯模式:最右側 `.track-add`(＋,56px),軌寬扣除其空間讓它在一畫面內可見;空軌顯示 `.track-remove`(×),只剩一軌時不顯示。
- 非編輯模式:搜尋後 0 筆的卡片隱藏,同軌其他卡片補滿;整軌都沒有可見卡片時該軌隱藏。
- 編輯模式:顯示所有啟用分類(含 0 筆),清單停用點擊,空軌顯示「拖到這裡」。
- 視窗寬度 < 900px:退回單欄、依內容高度(`perCategoryLimit` 筆)排列,隱藏編輯按鈕。

## 設定頁調整(追加)

### 軌道寬度移到排版工具列
- 設定對話框移除「欄位數」;`ui.colCount` 改由編輯模式工具列的「軌道寬度」設定:寬(2)/ 標準(3)/ 窄(4)/ 很窄(5)。
- 編輯中即時預覽,按「完成」才寫入;`Esc` 還原。
- 「重置排版」:草稿改回依分類順序輪流分配(仍需「完成」才儲存)。
- 編輯排版中匯入設定:先放棄草稿再套用匯入內容。

### 分類管理
- 手風琴:每個分類收成一列(開關 / 名稱 / 規則數 / 優先順序 / 刪除),點標題列展開,同時只展開一個。
- 篩選:全部 / 已啟用 / 已停用。
- 「新增分類」「重置為預設」移到區塊標題列;新增後自動展開、捲到該列並選取名稱。
- 移除「儲存分類」;對話框底部固定「取消 / 儲存」,一次儲存全部。分類有誤(如 key 重複)時擋下關閉並提示。
- 每次開啟設定以已儲存的分類重新渲染(按取消的修改不殘留)。
- 上 / 下按鈕改稱「提高 / 降低比對優先順序」,並加說明:顯示位置由排版決定,順序只影響比對優先順序。

## 排版模式(追加)

- `ui.layoutMode = 'grid' | 'free'`,在 設定 › 一般「排版模式」切換,按「儲存」套用。
  - `grid` 經典欄位:還原 v1.2.0 行為(CSS Grid 依序排入 N 欄、卡片依內容高度、整頁垂直捲動、無紀錄的分類隱藏);欄位數 `ui.colCount`(1–4)只在此模式顯示。
  - `free` 自由排版:軌道模式;軌道寬度存 `ui.trackCols`(2–5),與經典欄位數分開。
- 未設定時(`resolveLayoutMode`):存過 `ui.layout` 的視為 `free`,其餘(含新使用者)為 `grid`。
- 兩種模式的資料各自保留:切回 `free` 時原本的軌道排版仍在。
- 經典模式隱藏「編輯排版」按鈕、左右箭頭與排版工具列;編輯中切換模式會先放棄草稿。
